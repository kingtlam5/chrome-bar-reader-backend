# Stealth Memo Reader

偽裝成 Chrome 工具列的隱蔽閱讀器。

## 測試

開啟：https://kingtlam5.github.io/memo-reader/

本機測試：

```bash
git clone https://github.com/kingtlam5/memo-reader.git
cd memo-reader
python3 -m http.server 8765
```

瀏覽器開：**http://localhost:8765/index.html**

## 上傳偽裝背景

1. 準備最多 **20 張**全螢幕截圖
2. 撳右上角紫色 **B** 掣（或 Shift + ↻）
3. 一次過選取圖片（按選取順序填入第 1 至第 N 格）
4. 未上傳任何圖片時，下方顯示空白畫面
5. 用 **↻** 掣切換已上傳嘅背景

## 基本操作

| 操作 | 方法 |
|------|------|
| 匯入書 | ★ 掣 |
| 上一句 / 下一句 | Q / R 或 ← / → |
| 簡轉繁 | ⇄ 掣 |
| 老闆模式 | 空白鍵 |
| 全螢幕彈出視窗 | 拼圖掣 |
| 上傳背景 | B 掣 |
| 切換背景 | ↻ 掣 |
