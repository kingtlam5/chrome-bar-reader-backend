如何使用 Stealth Reader

兩個版本均為偽裝成 Chrome 工具列的閱讀器：句子顯示於網址列，下方可放置工作截圖。請使用下方按鈕切換免費版與 Pro 版說明。

開始之前

由免費會員中心啟動

  1. 登入後將進入免費會員中心。
  2. 按「啟動免費閱讀器」，會以一般瀏覽器視窗開啟。
  3. 免費版不會隱藏原生網址列，適合先熟悉操作。

開始之前

由付費會員中心啟動

  1. 使用 Pro 帳號登入付費會員中心。
  2. 先按「安裝為獨立視窗」（或使用 Chrome 選單的「安裝 Stealth Reader Pro」）。此步驟只需一次，效果等同 Windows 的 chrome.exe --app= 捷徑。
  3. 再按「啟動隱蔽閱讀器」。已安裝後，閱讀器會以無網址列的獨立視窗開啟。
  4. 如彈出視窗被攔截，請允許此網站的彈出視窗後再試。
