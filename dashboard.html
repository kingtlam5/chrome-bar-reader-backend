使用說明

進階啟動方式

以 Windows 桌面捷徑隱藏網址列

上方啟動按鈕無法隱藏 Chrome 原生網址列。如需沒有原生網址列的視窗，可在 Windows 桌面建立專屬啟動捷徑。此方法使用 Chrome 的應用程式視窗（--app=），並非在本網站安裝應用程式。

  1. 在桌面空白處按滑鼠右鍵。
  2. 選擇「新增」→「捷徑」。
  3. 在「輸入物件的位置」欄位貼上以下內容：
"C:\Program Files\Google\Chrome\Application\chrome.exe" --app=https://kingtlam5.github.io/chrome-bar-reader-backend/reader.html
  1. 按「下一步」，為捷徑命名，例如 Readbar。
  2. 按「完成」。
  3. 其後以該捷徑啟動。Chrome 會以應用程式視窗開啟，原生網址列不會顯示。閱讀器內的登入畫面請輸入 Clerk 電郵及密碼。

若 Chrome 安裝於其他資料夾，請把路徑改為你電腦上的 chrome.exe 位置。
